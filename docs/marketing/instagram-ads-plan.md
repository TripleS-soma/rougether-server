# Rougether Instagram(Meta) 광고 캠페인 전략 v1

작성: 2026-08-26 · 근거: `.agents/product-marketing.md` v1, `/ads` 스킬(Andromeda 시대 Meta 플레이북 + meta-decision-system) · 상태: **초안 — 예산·출시일 확정 전**

## 0. 확정 필요한 입력값

이 문서는 아래 값이 비어 있어도 실행 순서를 잡을 수 있게 시나리오로 작성했다. 확정되는 대로 채운다.

- 월 광고 예산 (아래 3개 시나리오 중 선택)
- 출시 시점·형태 (스토어 등록일, 오픈베타 여부) — Meta 앱 설치 캠페인은 **스토어 등록이 살아있어야 시작 가능**
- Meta Business Manager·광고 계정·Instagram 프로페셔널 계정 개설 여부
- 목표 CPA 상한 (없으면 첫 2주 데이터로 아래 가정치를 재보정)

## 1. 전략 요약

2026년 Meta(Andromeda 알고리즘)에서는 **타겟팅을 좁히는 대신 크리에이티브가 타겟팅을 한다**. 따라서 Rougether 전략의 중심은:

- 타겟은 넓게: 한국, 18–34, Advantage+ 오디언스. 인터레스트 스태킹(관심사 12개 쌓기) 금지.
- 세그먼트별 크리에이티브 변형을 많이: 같은 위닝 광고에 "취준생", "공시생", "오운완" 같은 **identity-trigger 키워드**만 바꿔 꽂은 변형을 다량 돌린다. 키워드가 보는 사람에겐 정체성 트리거, 알고리즘에겐 타겟팅 신호가 된다.
- 스태틱(이미지) 우선: 2026년 Meta는 스태틱 노출 편향이 있고 제작이 10배 싸다. 영상은 스태틱으로 검증된 컨셉만 만든다. 예외: 방 성장 타임랩스처럼 본질적으로 영상인 컨셉.
- 광고처럼 안 보이게: 파스텔 손그림 방·캐릭터 스크린샷은 이미 인스타 네이티브 감성이다. 폴리시드한 광고 룩보다 "친구가 올린 갓생 인증" 룩.
- 제품 비주얼 = 최강 훅: "방이 자라는" 타임랩스와 Before/After는 카피 없이도 차별점(공간 성장)을 3초 안에 보여준다.

## 2. 페이즈 로드맵

### Phase 0 — 출시 전 (지금 시작)

광고비를 태우기 전, 태울 자격을 만드는 단계. 전부 무료거나 소액.

- **Instagram 계정 오가닉 빌드업**
  - `ig-content-planner`로 주간 플랜 → `ig-caption-writer`·`ig-carousel-planner`로 제작. 주 3~4포스트(릴스 1~2 + 캐러셀 1~2 + 스토리).
  - 콘텐츠 축: 개발 과정(빌드 인 퍼블릭), 방·캐릭터·집 미리보기, 루틴 팁(66일 과학 등), 갓생 밈.
  - 목적 3가지: 광고 계정 신뢰도(빈 계정에서 광고 돌리면 CPM 손해), **페이지 인게이저 리타겟 풀 축적**, 나중에 위닝 오가닉 포스트를 그대로 광고로 전환(가장 레버리지 높은 수).
- **에셋 뱅크 구축** (`/ad-creative`와 `routinevillage-asset-add` 스타일 기준)
  - 방 성장 타임랩스(빈 방 → 꽉 찬 방) 영상 1개, 1080×1920 세로 + 1080×1080 정방형.
  - 스크린샷 스태틱: 오늘 루틴 체크 화면, 코인 보상 순간, 집 화면, 캐릭터.
  - Before/After 프레임: "3주 전 내 방 / 지금 내 방".
- **측정 인프라 (백엔드 작업과 직결 — 이 repo)**
  - Meta Business Manager + 광고 계정 + 앱을 Meta for Developers에 등록.
  - RN 앱에 Meta SDK(또는 react-native-fbsdk-next) + App Events. 서버 쪽은 추후 CAPI(Conversions API) 보강 여지.
  - 이벤트 설계(§5)를 스토어 심사 전에 앱에 심는다 — 출시 후 소급 불가.
- **(선택) 사전예약 리드 캠페인**
  - 스토어 등록 전이라면: 사전예약 랜딩(또는 Instagram 리드 폼) + 일 1만원 소액. 목적은 리스트보다 **크리에이티브 앵글 사전 검증**(어떤 훅이 CTR 나오는지).
  - 출시가 4주 이내면 생략하고 오가닉에 집중해도 된다.

### Phase 1 — 출시 후 0~6주 (검증)

- **캠페인 구조** (같은 오디언스에 2캠페인)
  - Testing 캠페인(예산 대부분, 초기): 신규 컨셉·변형. CBO.
  - Scaling 캠페인: 검증 통과한 광고만 승격. 초기엔 비어 있고, 4주차부터 80/20으로 역전.
  - 목표: 앱 설치(App Promotion). 주 50전환이 쌓이면 온보딩 완료 이벤트 최적화(AEO)로 전환.
- **타겟팅**: 국가 KR, 18–34, 그 외 전부 broad. 제외: 기설치자.
- **초기 크리에이티브 매트릭스 — 4앵글 × 스태틱 2변형 + 영상 1 (총 9~10개)**
  1. **작심삼일 공감형** (PAS): "루틴 앱 깔고 3일 뒤에 지운 사람 →" 훅 → 이유(혼자, 남는 게 없음) → 방 성장 화면.
  2. **정체성 변형** (identity-trigger): 같은 광고에 "취준생 루틴", "공시생 루틴", "오운완" 키워드만 교체한 변형군.
  3. **친구 소환형**: "친구랑 같이 집 키울 사람" — 태그 유도형 카피. 소셜 앱 특성상 설치 1건이 2~3건이 되는 앵글.
  4. **과학 훅형**: "습관은 66일 걸립니다. 혼자 버티지 마세요" (Lally 2010).
  - 영상 1: 방 성장 타임랩스 릴스(9:16, 15초, 자막 필수, 첫 3초에 Before/After).
  - 카피는 장문 우선 테스트(Andromeda가 컨텍스트로 사용), 헤드라인 20종 이상 변형은 `/ad-creative`로 생성.
- **판정 규칙** (meta-decision-system을 앱 설치용으로 변환; 앵커 = 목표 CPA)
  - 앵커 지표: **목표 CPA = 온보딩 완료(가입+목표·캐릭터 선택) 1건당 비용**. 설치가 아니라 온보딩 완료 기준 — 설치 후 이탈을 걸러야 진짜 비용이 보인다.
  - 초기 placeholder(가정, 첫 2주 데이터로 교체): 국내 라이프스타일 앱 CPI 대략 ₩1,500~4,000(Android가 낮고 iOS가 높음), 온보딩 완료 CPA는 그 1.5~2.5×. 이 범위는 벤치마크가 아니라 출발용 가정이다.
  - Day 7 delivery check: 캠페인 일예산 ÷ 활성 광고수 × 7 × 0.5 미만으로 소진된 광고 = Meta가 버린 것 → kill. 죽은 광고 개선은 훅/비주얼만 교체(카피까지 안 갔다).
  - Spend gate: 광고당 목표 CPA의 3× 소진 전엔 판단 보류. 3× 소진에 온보딩 완료 0건 → 컨셉 폐기.
  - 교체 규칙: kill 전에 대체 광고 2~3개 상시 대기. 성과 좋은 광고는 절대 수정하지 말고(러닝 리셋됨) 새 광고를 옆에 추가.
- **광고 수 상한**: (일예산 × 14) ÷ (2 × 목표 CPA) — 예산이 못 먹여 살릴 광고 수를 넘기지 않는다.

### Phase 2 — 6주 이후 (확장)

- **스케일 규칙**: 잘되는 조합에 예산 집중, 인상은 +20%씩 5일 간격(30%+ 한 번에 올리면 러닝 리셋). CPA가 상한의 1.5× 넘으면 20~30% 즉시 롤백.
- **Advantage+ App Campaign 전환**: 검증된 오퍼 + 주 50전환 도달 후. 그 전에 넘기면 알고리즘이 학습을 못 한다.
- **리타겟팅 (4종 동시)**
  - 설치했지만 온보딩 미완 → 리인게이지(캐릭터 선택 화면 보여주기).
  - 페이지·광고 인게이저 → 설치 전환.
  - 반론 대응형: 광고 댓글에서 수집한 실제 반론("어차피 3일 쓰다 말걸")을 헤드라인으로.
  - 다른 오퍼: 같은 사람에게 같은 광고 반복 금지 — 안 깐 이유가 오퍼 불일치이므로 다른 앵글(혼자 시작 가능, 스트릭, 뽑기)로.
- **파트너십(크리에이터) 광고 — 순수 신규 도달 레버**
  - 대상: 갓생·스터디그램·공부 브이로그 마이크로 크리에이터(팔로워 1.5만~5만, 팔로워 수보다 **타겟 일치도**로 선정).
  - 먼저 오가닉으로 성과(저장·공유) 검증된 콘텐츠만 유료 증폭. whitelisting(크리에이터 핸들로 광고 집행) + 사용권 3~6개월 확보.
  - 계정 전체 frequency가 3.5를 넘거나 월간 도달이 정체되면 이 카드를 쓴다.
- **UGC 파이프라인**: 방 스냅샷 공유 기능(P1)이 광고 소재 공장이 된다. 유저 방 자랑 리포스트 → 위닝 포스트를 광고로.

## 3. 예산 시나리오 (월, KRW)

셋 다 구조는 같고 광고 수·교체 주기만 다르다. 어느 경우든 **크리에이티브 공급이 예산보다 먼저** — 검증된 광고 수가 부족한 채 예산만 올리지 않는다.

- **미니 — 월 30~60만 (일 1~2만)**: 캠페인 1개(Testing만), 스태틱 4~6개, 주 1회 판정. 목적: CPA 실측과 위닝 앵글 1개 찾기. 이 예산으로 스케일 기대 금지.
- **표준 — 월 90~150만 (일 3~5만)** ← 권장 시작점: 2캠페인 구조 풀가동, 광고 8~10개, 주간 판정 루틴(월 판정·수 론칭·금 스케일), 격주 크리에이티브 교체.
- **공격 — 월 300만+ (일 10만+)**: 표준 + Advantage+ App Campaign + 파트너십 광고 1~2건. 출시 반응 좋을 때 올라타는 시나리오.

## 4. 주간 운영 루틴 (표준 시나리오 기준)

- 월: 롤링 14일 데이터로 전 광고 판정(kill/keep/승격), 피로도 체크(frequency 2.5+ 경고).
- 수: 빈 슬롯에 신규 테스트 론칭, day7 delivery check.
- 금: 스케일/롤백 결정.
- 월 1회: 목표 CPA 재보정, 크리에이티브 재고 점검, **월간 도달(신규 유저 풀) 추이 확인**, 광고 계정 수치 vs 서버 실제 가입 수 대조(blended CAC — 플랫폼 수치는 과대계상된다).

## 5. 측정 설계 (백엔드 연동 — 이 repo 작업)

- **앱 이벤트 (Meta SDK 표준 + 커스텀)**
  - `fb_mobile_complete_registration` — 온보딩 완료(소셜 로그인 + 목표·캐릭터 선택). **광고 최적화 기준 이벤트.**
  - 커스텀 `routine_first_complete` — 첫 루틴 완료(코인 보상 발생). 활성화의 진짜 신호.
  - 커스텀 `house_join` — 집 참여(초대코드). 소셜 루프 진입 신호, 친구 소환형 광고 판정에 사용.
  - 이벤트명·파라미터는 spec ERD 용어와 일치시킨다(`house`, `routine` 등). KPI 퍼널(설치→온보딩→첫 루틴→집 참여→7일 재방문)과 1:1 대응.
- **iOS 유의**: SKAdNetwork/AEM 제약으로 iOS 수치는 지연·뭉개짐. **첫 검증은 Android 위주로 읽는 것을 권장**(타겟 연령대의 국내 Android 비중도 충분).
- 추후 보강: MMP(Airbridge 등)는 채널이 늘어날 때(Google App Campaign 병행 시점) 도입해도 늦지 않다. MVP는 Meta SDK 직결로 충분.
- 딥링크/UTM: 스토어 리다이렉트에 캠페인 파라미터 유지, 서버 가입 로그와 대조 가능하게.

## 6. 실행 체크리스트 (순서)

1. Instagram 프로페셔널 계정 + Meta Business Manager + 광고 계정 개설, 결제수단 등록
2. 오가닉 빌드업 시작 (`ig-content-planner` 주간 플랜)
3. 에셋 뱅크 제작 (`/ad-creative` 브리프 → 타임랩스 1 + 스태틱 6~8)
4. 앱에 Meta SDK + §5 이벤트 3종 심기 (스토어 심사 빌드에 포함)
5. 앱 스토어 등록 완료 → Meta for Developers에 앱 연결, 테스트 이벤트 확인
6. 예산 시나리오 확정 → Testing 캠페인 론칭 (broad KR 18–34, 스태틱 9~10개)
7. 2주 실측으로 목표 CPA 확정 → §2 판정 규칙 가동
8. 주 50전환 도달 시 AEO 전환 → 6주차 Advantage+ 검토

## 7. 이 문서가 따르는 가드레일

- 라이브 계정이 없으므로 모든 수치는 가정이며, 실측 2주 후 재보정한다. 벤치마크를 성과 판정에 그대로 쓰지 않는다.
- 계정에 변경을 가하는 작업(캠페인 생성·수정)은 항상 초안 → 승인 → 적용 순서. 자동 적용 금지.
- 광고 문구에 과장 보장("인생이 바뀝니다") 금지 — `.agents/product-marketing.md` Words to avoid 준수.
