# 거미줄 발생·청소 알림

2026-09-07 사용자 결정에 따라 봇의 거미줄 청소 행동을 제거했다. 방 주인과 같은 집 ACTIVE 구성원의 청소 API·최초 3코인 보상은 유지한다. 한 번 발생한 거미줄은 접속만으로 사라지지 않는다.

- 발생 조건은 기존의 2일 미접속, 매일 12:30 KST 판정과 기동 시 보정을 유지한다.
- 신규 발생·재발생 시 주인에게 `ROOM_COBWEB_APPEARED` 알림을 저장한다. 제목은 `방에 거미줄이 생겼다냥!`, 본문은 `방에 놀러 와서 거미줄을 톡 눌러 치워주세요!`다. `refId`는 방 주인 user id이고 설정 그룹은 `REMINDER`다.
- 사용자 행 잠금 아래 거미줄 발생과 알림 내역을 같은 트랜잭션으로 저장한다. 반복·동시 실행은 같은 발생 회차의 알림을 추가하지 않는다.
- 발생 커밋 뒤 기존 `ReminderPushWriter`로 FCM을 발송한다. 미처리 `PENDING`은 5분마다 회수한다. 재발생하면 이전 회차의 `PENDING`은 만료한다. 이미 청소했거나 탈퇴한 사용자의 발생 알림은 발송하지 않는다.
- FCM은 기존 best-effort 계약을 따른다. 알림 설정 `ALL`/`REMINDER`가 꺼져 있으면 `BLOCKED`, 토큰이 없거나 발송 실패면 `FAILED`로 기록한다. FCM 성공 직후 프로세스가 종료되는 외부 전송 경계까지 정확히 한 번을 보장하지는 않는다.
- FCM data는 `type=ROOM_COBWEB_APPEARED`, `screen=myRoom`, `notificationId`다. 모바일 신규 타입 라우팅이 반영되면 알림 탭으로 내 방에 이동한다. 구버전도 알림을 표시하고 알림함으로 이동할 수 있다.
- 친구 청소 알림은 기존 `ROOM_COBWEB_CLEANED`/`HOUSE` 계약을 유지하고 제목을 `친구가 거미줄을 청소해줬다냥!`으로 바꾼다. 본문에 청소한 친구의 닉네임을 표시한다. 본인 청소는 알림을 보내지 않는다.

배포에는 user-api와 batch 변경이 모두 필요하다. 새 타입을 읽을 수 있는 user-api를 먼저 준비하고 batch 발생 알림을 활성화해야 한다. 신규 API나 DB migration은 없다. 실기기 FCM 수신은 별도 확인이 필요하다.
