# 관리자 알림 발송

관리자 화면 `/notification-campaigns`에서 제목과 내용을 작성하고 전체 사용자 또는 선택한 사용자 ID를 대상으로 공지한다. 앱 알림함 저장은 항상 수행하고 푸시는 운영자가 별도로 선택한다. 접속 팝업과 이벤트 바로가기, 앱의 별도 '새 소식' 목록을 편집하는 기능은 아니다.

## 발송 절차

1. 대상과 내용을 입력한다. 기본값은 선택한 사용자, 푸시 미선택이다.
2. 미리보기에서 알림함 대상 수, 푸시 설정 허용/차단, 등록된 기기가 없는 사용자 수를 확인한다.
3. 초안을 저장한다. 이때 수신자 목록이 고정되며 사용자에게 알림을 보내지 않는다.
4. 이력의 발송 검토에서 내용과 인원을 다시 확인하고 확인 체크 후 발송한다.
5. 새로고침으로 처리 결과와 실제 발송 승인자, 승인 시각을 확인한다.

선택 대상은 최대 1,000명, 전체 대상은 최대 10,000명이다. 봇, AI 계정, 탈퇴 사용자는 제외한다. 초안 이후 탈퇴한 대상도 전송 시 제외한다. 미리보기와 저장 사이에 대상 상태가 달라질 수 있으므로 최종 확인은 저장한 초안 기준이다.

알림함 저장 완료와 푸시 접수는 구분한다. 처리 완료는 수신자별 저장 작업이 끝났다는 뜻이다. 푸시 접수는 FCM이 요청을 받아들였다는 뜻이며 실제 기기 도착이나 읽음을 보장하지 않는다. 푸시 미선택은 `NOT_REQUESTED`, 설정 차단과 기기 미등록은 각각 별도 결과로 표시한다. 푸시는 기존 커밋 후 best-effort 경로를 사용하며 자동 재발송하지 않는다.

## 중복과 재시작

초안 생성은 운영자와 `requestId`로 중복을 막으며 같은 ID의 다른 내용은 거절한다. 발송 시작은 캠페인 잠금과 고정 인원 확인을 거친다. 수신자별 잠금 아래 알림 생성과 처리 표시가 함께 커밋되므로 스케줄러 재실행으로 알림함에 같은 공지를 중복 생성하지 않는다. 알림 하드 삭제 후에도 캠페인 이력은 남고 다시 생성하지 않는다.

기본 스케줄러는 `admin.notification-campaigns.dispatch-enabled=true`이며 테스트에서만 false로 끈다. 캠페인 생성, 조회, 앱 시작만으로 발송을 승인하지 않는다. 이미 승인된 처리 중 캠페인은 재시작 후 이어서 처리한다.

## 배포와 호환성

- V98은 캠페인과 수신자 스냅샷을 추가한다. 알림 FK는 `ON DELETE SET NULL`로 회원탈퇴와 알림 삭제를 허용한다.
- `ADMIN_NOTICE`, `NOT_REQUESTED`를 읽을 수 있는 새 **user-api 전체 전환을 먼저 확인한 뒤** 관리자 발송을 사용한다. 구버전은 새 enum 행을 읽지 못하므로 발송 후 구버전 user-api로 단순 롤백하지 않는다.
- 사용자 알림함은 새 공지를 일반 알림으로 표시한다. 기존 앱에서 클릭 목적지는 알림함이며 임의 외부 URL이나 이벤트 탭으로 바로 이동하는 계약을 추가하지 않는다.
- 역할은 ADMIN/SUPER_ADMIN으로 제한하고 세션 인증, CSRF를 유지한다.
- 실사용자 테스트 또는 실제 푸시 발송은 이 변경의 검증에 포함하지 않는다. 로컬 H2와 가짜 FCM으로 발송 흐름을 검증한다.

## 코인 보상 변경과 함께 배포할 때

루틴과 할 일 완료의 합산 일일 기본 한도는 KST 기준 100코인이다. 크리스마스 가구 종류별 +10%는 한도 밖의 추가 코인이며 성장 포인트는 기본 지급 원금만 반영한다. 완료 취소는 저장한 실제 지급액과 성장 지급액을 회수한다.

V99는 nullable 원금 컬럼만 추가하고 기존 행을 null로 유지한다. 새 코드는 null 원금을 총 지급액으로 읽는다. 추가 코인이 없는 완료와 취소는 원금 필드를 null로 저장해 구버전 writer가 총액을 갱신해도 정확히 집계한다. 추가 코인이 있는 완료만 명시적 원금을 기록하므로 **모든 user-api 전환 전에는 보너스를 켜지 않는다.** `CHRISTMAS_COIN_BONUS_ENABLED` 기본값은 false다. 이벤트 공개 시 새 버전 전체 전환을 확인하고 true로 켠다. 활성화 후 구버전으로 롤백하지 않는다. 기간 종료는 서버 KST 2026-12-26 00:00이며 기본 한도 100코인은 이후에도 유지한다.

이 문서는 크리스마스 뽑기, 누적 출석, 접속 팝업의 구현 또는 공개 완료를 의미하지 않는다.
