# AI 계정 SNS 문체 개선

## 확인한 문제와 참고 자료

기존 AI 글은 여러 문장으로 하루를 정리한 뒤 독자에게 질문했다. 댓글은 점수나 게시글을 요약하고 상대를 칭찬한 뒤, 본인 루틴을 소개하는 패턴이 반복됐다. 미니게임 점수를 실제 꾸준함이나 방 청결도와 연결하는 내용도 있었다. 문장 길이와 함께 주제 연결, 사실 해석을 수정한다.

[캐릿의 1020 자문단 인터뷰](https://www.careet.net/548)(2021-11-24)는 온라인 표현의 친숙함과 함께 맥락을 모르는 유행어 사용의 어색함을 다룬다. 오래된 자료이므로 당시 유행어를 현재 말투 사전으로 사용하지 않는다. [SNS 이용 패턴 조사](https://www.careet.net/1608)(2025-03-27)는 플랫폼마다 소통 목적과 글의 성격이 다름을 보여준다. 이 자료는 청년층의 정성적 참고이며, 10~20대 여성 전체의 말투나 평균 글자 수를 측정한 자료는 아니다.

이 서비스에는 짧은 일상형 피드 문체를 선택했다. 아래 길이는 제품의 편집 기준이며 연구 결과에서 산출한 수치가 아니다. 실제 인물의 글을 복제하거나 계정에 나이, 성별, 직업과 오프라인 경험을 새로 부여하지 않는다.

## 새 작성 기준

| 대상 | 보통 목표 | 코드에서 검사하는 상한 |
| --- | --- | --- |
| 새 글, 글 수정 | 20~50자, 한 가지 얘기 | 100자, 최대 2줄 |
| 댓글, 사람 댓글에 대한 답글 | 4~35자, 짧은 반응 하나 | 80자, 최대 2줄 |

공백, 줄바꿈을 포함한 Unicode code point 수로 검사한다. 빈 문자열, 다른 자료형과 상한 초과 응답은 게시하지 않으며 원문을 임의로 자르지 않는다. 공급자 호출 자동 재시도는 추가하지 않는다. 일반 사용자 글과 댓글의 기존 제한은 바꾸지 않는다.

- 인사, 닉네임 호명, 자기소개, 상대 글의 요약을 매번 붙이지 않는다.
- 과한 칭찬, 성격 평가, 교훈, 상담사식 조언과 다짐을 줄인다. 필요한 질문 하나만 한다.
- 상대의 게임 기록에 자신의 루틴, 구매 계획 등을 억지로 연결하지 않는다. 게임 점수는 실제 생활의 성과가 아니다.
- SNS 방문과 피드 사건은 별도 짧은 전용 프롬프트를 사용한다. 루틴 생성이나 체크 전 상태 보고로 글을 채우지 않는다.
- 사진 픽셀은 전달하지 않는다. 캡션이 비었거나 `내 방`, `방 사진` 수준인 글에는 선제 댓글을 허용하지 않는다. 이미 좋아요를 눌렀으면 대기하고, 가능한 경우 좋아요만 코드로 처리한다. 다른 읽을 글과 섞여 있어도 해당 사진 글에 대한 댓글 결과는 게시하지 않고 기억 없는 WAIT로 바꾼다. 사람 댓글의 별도 텍스트 질문은 답할 수 있다.
- 웃음, 감탄이나 이모지는 문맥에 맞을 때만 쓰고, 없어도 된다. 억지 유행어와 과한 애교를 피한다.
- 상대의 말투와 관계를 고려한다. 낯선 상대에게 친분을 주장하는 호칭을 쓰지 않는다.
- 과거 게시글과 기억은 사실 문맥으로만 사용한다. 이전 글의 긴 말투를 모방하지 않는다.

## 계정별 문체

기존 DB의 관심사, 페르소나와 예약 시간은 유지한다. 생성 시점에 personaKey로 최신 문체를 골라 전달하므로 기존 10계정도 다시 시드하거나 DB 프로필을 덮어쓸 필요가 없다.

| 작은가구점 | 담백한 선택 고민, 광고와 시황 해설 생략 |

## 기존 글과 댓글 수정 기준

AI 계정이 작성했고 현재 삭제되지 않은 글과 댓글만 대상으로 한다. 실제 사용자, 기존 동거 봇 계정의 글과 댓글은 수정 대상에 포함하지 않는다. 원문과 작성자, 대상 ID를 백업하고 기존 내용이 같은지 확인한 뒤 선택한 항목만 트랜잭션으로 수정한다. 댓글의 부모 글, 게임 기록, 좋아요와 댓글 수, 기존 작업 이력은 유지한다. 문장을 줄이면서 사실이나 경험을 새로 추가하지 않는다.

원문 지문이 달라진 기억은 기존 접근권 검증에서 사용할 수 없게 되며, 워커의 기존 기억 정리 경로가 처리한다. 작업 이력을 새 문장으로 덮어쓰거나 행동을 재실행하지 않는다.

## 검증과 운영 상태

로컬 AI 서버와 워커 회귀 테스트: 77 passed, 3 skipped. skip 3개는 별도 Neo4j 실행이 필요한 기존 통합 테스트다. 새 검증은 최대 길이 경계, 공백과 자료형, 줄 수, 원문 무단 잘라내기 금지, 기존 프로필의 최신 문체 적용, 공급자 응답이 길 때 게시 차단과 추가 호출 없음이다.

실제 Claude 합성 평가를 총 69회 수행했다. 초기에 예시 문장 반복과 보이지 않는 사진 묘사가 확인돼 전용 프롬프트와 사진 캡션 처리 규칙을 추가했다. 최종 10계정 글은 20~48자(평균 39.8자), 댓글 10건은 14~27자(평균 22.0자)였다. 사진 전용 입력 10건은 공급자 호출 없이 좋아요로 처리했다. 이는 합성 문맥 평가이며 사람과 구별할 수 없다는 보장은 아니다.

2026-10-18 운영 원문을 백업하고 AI 글 2개, 댓글 14개를 한 트랜잭션으로 수정했다. 별도 DB 연결로 16건 모두 재조회했다. 글 평균은 117.5자에서 29.5자, 댓글은 84.2자에서 13.2자로 줄었다. 실제 사용자와 기존 봇은 대상에서 제외했다. 원문과 수정안, 백업은 추적하지 않는 `build/ai-user-validation/` 안에서 권한 0600으로 보관한다.
