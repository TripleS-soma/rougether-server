# 삭제 대상과 소셜 접근 정책 중복 제거

2026-10-25 | 기준 main `8823babf935fab79c79900e9535a38dbf683588e`

같은 정책을 두 곳에서 각각 구현하던 세 부분을 공통화했다. API 응답, 삭제 범위, 접근 권한과 AI 참여 한도는 유지한다.

## 전후 비교

| 대상 | 변경 전 | 변경 후 | 줄어드는 수정 부담 |
| --- | --- | --- | --- |
| 카테고리 PURGE | 기록과 사진의 삭제 쿼리가 같은 조건을 각각 정의 | `CategoryPurgeQuery.LOG_CONDITION` 공유 | 삭제 대상 조건 2곳 → 1곳 |
| 피드 답글 접근 | 조회와 작성 서비스가 원댓글 접근 조건을 각각 검사 | 기존 `FeedAccess.requireThreadVisible` 호출 | 접근 검사 2곳 → 1곳, 조회 서비스의 차단 저장소 직접 의존 제거 |
| AI 선제댓글 참여 | 후보 선정과 실행 직전에 같은 두 COUNT 조건 반복 | 같은 클래스의 `hasReachedPostParticipationLimit` 호출 | 참여 제한 규칙 2곳 → 1곳 |

DB 조회 수나 응답 속도를 개선하는 작업은 아니다. 정책 정의를 한 곳에 두어 한쪽만 수정했을 때 생기는 차이를 줄인다. 사진과 기록의 DELETE는 기존처럼 두 번 실행하고, AI도 후보 선정과 실제 실행 시 각각 현재 상태를 조회한다.

## 1. 카테고리 삭제: 기록과 사진을 같은 기준으로 판단

카테고리의 기록을 지울 때 다음 두 종류는 보존해야 한다.

- 같은 루틴 계보에 살아 있는 버전이 남아 있는 기록과 사진.
- 삭제 당일 보상을 받은 기록과 사진.

공통 JPQL 조건은 `domain.routine.repository` 안에서만 사용한다. 두 저장소가 같은 문자열 상수를 참조하며, 추가 조회로 삭제할 ID를 먼저 모으는 방식은 도입하지 않는다.

기존 `CategoryService`의 소유권 검사, 살아 있는 루틴의 삭제 거절, 동일한 KST 날짜 전달, 사진 → 기록 삭제 순서와 단일 트랜잭션을 유지한다. `flushAutomatically`, `clearAutomatically`도 유지한다. 다른 카테고리의 기록, 루틴 row, 카테고리 참조와 스트릭을 변경하지 않는다.

## 2. 피드 답글: 조회와 작성에서 원댓글 접근 규칙 공유

공통 검사는 해당 게시물의 댓글인지, 최상위 원댓글인지, 요청자가 원댓글 작성자를 차단했는지 확인한다. 실패 시 기존 `FEED_COMMENT_NOT_FOUND`를 반환한다.

삭제되거나 작성자가 탈퇴한 원댓글 아래에서도 살아 있는 답글을 조회하고 그 답글에 계속 답할 수 있다. 직접 답할 대상의 삭제·탈퇴·봇 검사는 기존 `replyTarget`에 남긴다. 두 검사는 목적이 다르므로 합치지 않는다.

작성의 회원/게시물 잠금과 성공 요청 재시도 처리 순서, 조회의 읽기 전용 트랜잭션, 요청자 기준 단방향 차단을 유지한다. 원댓글 작성자가 요청자를 차단한 역방향 관계를 새 거절 조건으로 추가하지 않는다.

## 3. AI 댓글: 후보 선정과 실행에서 같은 참여 제한 사용

동일 AI가 해당 글에 이미 선제댓글을 달았거나, 글의 전체 AI 선제댓글이 2개 이상이면 참여를 제한한다. 이 조건만 private 메서드로 옮긴다.

관찰 이후 다른 AI가 댓글을 달 수 있으므로 실행 직전에도 DB를 다시 조회한다. 첫 조건이 참이면 두 번째 COUNT를 생략하는 기존 동작도 유지한다. 일일 한도, 쿨다운, 본문 중복 검사와 거절 사유의 우선순위는 바꾸지 않는다.

사람 댓글에 대한 반응 작업(`sourceType=FEED_COMMENT`)의 기존 예외를 유지한다. 선제댓글의 글별 참여 상한을 좋아요 실행까지 확대하지 않는다.

## 기존 동작을 확인하는 테스트

생산 코드를 바꾸기 전에 아래 회귀 검증을 보강하고, 같은 테스트를 변경 후 다시 실행했다.

- **카테고리:** 오늘 지급/미지급/과거 지급 기록의 사진 처리, 다른 카테고리의 닫힌 루틴 보존, 계보 루트의 `originRoutineId`가 null인 경우와 자기 ID인 경우. 기존 삭제 거절과 전체 롤백 테스트도 실행한다.
- **피드:** 원댓글 작성자 탈퇴 후 남아 있는 답글에 새 답글 작성, 원댓글 작성자가 요청자를 차단한 경우의 조회/작성 허용. 기존 삭제 원댓글, 요청자 차단, 잘못된 부모, 재시도와 알림 테스트도 실행한다.
- **AI:** 선제댓글 0→1→2개에 따른 후보 변화, 동일 AI의 다른 본문 재참여 거절, 관찰 후 상한에 도달한 글의 실행 거절, 해당 글 좋아요 허용과 사람 요청 답글 예외.
