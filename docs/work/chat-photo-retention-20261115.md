# 채팅 사진 30일 만료와 기기 캐시 계약

2026-11-15 사용자 결정으로 사진 파일 보관을 메시지 전송 시각부터 30일로 제한하고 모바일 앱 전용 디스크 캐시를 허용한다. 기존 무기한 보관/기기 저장 금지 계약을 대체한다.

- 보낸 사진의 정본은 `chat_messages.created_at + 30일`이다. 업로드의 `expires_at`은 구버전 writer가 배포 전환 중 그대로 남길 수 있으므로 보낸 사진의 권한/응답/정리 판정에 의존하지 않는다.
- 기존 사진도 메시지 전송 시각부터 계산한다. 만료 시각부터 GET image/metadata가 404이며 앱도 저장 파일을 표시하지 않는다. 글과 메시지 기록은 유지한다.
- `GET /api/v1/chat/images/{imageId}/metadata`는 현재 열람 권한을 확인하고 `ChatImageResponse`(expiresAt 포함)를 반환한다. 인증/인가/만료는 이미지 읽기와 같고 S3를 읽지 않는다. 헤더는 private, no-store다.
- V109는 nullable purged_at을 추가하고 기존 전송 사진의 expires_at을 보정한다. 파일 삭제 성공 시에만 purged_at을 기록하며 실패 시 기존 정리 작업이 재시도한다. 만료된 전송 사진 행은 만료 표시와 멱등 재전송 비교용으로 남긴다. 회원 탈퇴/집 해체/운영자 삭제는 기존 행 삭제 정책을 유지한다.
- 서버를 먼저 배포한 뒤 모바일을 배포한다. 신규 모바일이 구버전 서버 metadata 404를 캐시 권한 거부로 다루므로 서버 선행이 필요하다. 구버전 모바일은 만료 안내를 해석하지 못하더라도 서버 바이트 조회가 차단된다.
- 운영 배포는 docker-publish.yml의 blue-green 경로만 사용한다. 이 작업 중 운영 변경은 수행하지 않는다.
