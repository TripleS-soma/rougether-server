# 7일 출석과 AI 가구 만들기

2026-09-07 사용자 요청: 7일 연속 출석 완료 보상을 지정 가구 대신 AI 가구 생성권 1회로 변경하고, 메인 화면에서 사진으로 가구를 만들 수 있게 한다.

## 적용 내용

- 출석은 사용자가 `오늘 출석하기`를 누르는 수동 방식으로 유지한다.

- `rewardItemId=null`, `targetDays=7`인 새 출석 이벤트는 생성권 1회를 지급한다. 기존 가구 이벤트는 보존한다.
- `reward.type=GENERATION_CREDIT`, `dailyRewards[].generationCreditAmount`로 앱이 새 보상을 구분한다.
- 출석·코인·생성권 원장을 하나의 트랜잭션으로 처리한다. 사용자 잠금과 완료 기록으로 중복 지급을 막는다.
- 기존 `codex/furniture-credit-payments`의 생성권 계정·예약·정산 구현을 기반으로 재사용한다. 해당 기반 코드는 main에 없어서 이 브랜치에 함께 포함되어 있다. 유료 판매는 기본 비활성이며 이번 이벤트가 판매를 활성화하지 않는다.
- main이 V66을 사용하므로 미배포 생성권 DDL은 V67, 출석 확장은 V68로 정리했다. 배포된 V47과 main V66은 수정하지 않았다.
- 생성 접수는 기본적으로 생성권을 요구한다. 기존 무료 작업과 완료 후 피드백은 추가 차감하지 않는다. 실패 작업은 예약을 반환한다.
- 모바일은 메인 AI 아이콘, 사진 선택·중복 접수 방지·진행 조회·가구함 배치를 연결한다. 공개 카탈로그에 없는 개인 생성 가구는 본인 인벤토리와 합쳐 표시한다.

## 검증

- 서버 전체 `./gradlew test` 통과. 기존 가구 출석·생성·결제 정산 회귀 포함.
- 신규 7일 동시 출석, 원장 실패 롤백, 생성권 예약·업로드 실패 반환, 하루 누락 리셋, 생성권 부족 접수 거부 테스트 통과.
- 관리자 7일 생성권 이벤트 생성과 다른 목표일 거부 테스트 추가.
- 모바일 타입·린트·포맷 검사 및 전체 Jest 203개 스위트, 1728개 테스트 통과. 최종 UI 변경 관련 테스트도 별도 통과.
- Expo SDK 55 웹 갤러리의 390px 화면에서 7일 출석표와 가구 만들기 화면을 확인했다. 실제 기기 사진 업로드와 외부 AI 제공자를 사용하는 생성 호출은 별도 배포 검증 대상이다.

## 운영 반영

서버·모바일 배포 후, 기간을 지정해 관리자 이벤트 생성 API를 호출한다. 운영 시작일·종료일은 아직 정하지 않았으며, 이 작업에서 운영 이벤트 생성이나 기존 이벤트 변경은 수행하지 않는다. 생성 워커·AI 키·스토리지가 기존 파이프라인 설정으로 활성인지 확인해야 한다. `billing.require-credits=true`를 명시하여 생성권 사용 조건을 유지한다.

스펙 정본 변경은 별도 rougether-spec 브랜치의 `domains/attendance`에 있다.
