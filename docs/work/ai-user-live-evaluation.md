# 가상 사용자 실제 모델 평가

유료 호출은 `AI_USER_LIVE_EVAL=true`로 명시한 별도 실행에서만 수행한다. 일반 테스트/CI는 건너뛴다.
임시 MySQL과 가상 대화만 사용하고, 실행당 외부 호출 수를 60회 이내로 제한한다.
요금·크레딧 잔액은 제공자 자료로 따로 확인하며 토큰 수를 달러 실결제로 표시하지 않는다.

## 성공 조건

- 신규 AI 10개 모두 실제 모델의 JSON을 받아 HTTP 제어 API로 실행하고 DB 영수증을 남긴다.
- 신규 계정은 예약 작업에서 목표 선택 → 캐릭터 선택 → 첫 루틴/투두 생성을 진행한다.
- 먼저 등록된 예약 10개보다 사람 댓글 10개가 먼저 처리된다.
- 사람 댓글·집 채팅에 해당 글/방으로 답한다. AI 답변에서 새 반응 작업은 생성되지 않는다.
- 워커 프로세스를 재시작해도 DB 기억이 다음 모델 입력에 포함되고, 기록 이름을 닉네임과 혼동하지 않고 답한다.
- 다른 사용자 소유권, 허구의 인간 정체성, 원문의 지시 주입에 관한 답변을 확인한다.
- 모든 호출의 모델·토큰·지연·오류, 실제 행동과 DB 상태를 별도 보고서에 남긴다.

첫 시도 성공률을 그대로 기록한다. 재실행으로 실패 기록을 덮어 성공률을 부풀리지 않는다.
문맥·말투·정체성 답변은 원문을 읽어 수동 평가하고, 영수증·우선순위·기억 전달은 코드로 판정한다.
