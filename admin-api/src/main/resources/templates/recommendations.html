AI 조정 추천 퍼널 관측

주(생성 주, 일~토 KST)마다 추천 퍼널과 CONTROL/TREATMENT 완료율 변화를 확인합니다.

이번 주 생성 — 실패 패턴 룰 기반 조정 제안
수락 — 사용자 탭으로 루틴에 적용됨
무시 — 만료 = 무반응 종결(기한·무효)
수락률 — 효과 = 수락 전후 주 완료율 델타
지표 기준 주는 추천이 생성된 시각(KST) 기준 일~토 주이며, 이번 주 배치 생성분이 보이도록 진행 중 주가 첫 행입니다. 만료는 상태 전이 없는 무반응 종결 — ACTIVE인 채 expires_at(생성 후 7일)이 지났거나, 루틴 삭제·선행 스케줄 수정으로 무효가 되어 사용자 목록에서 빠진 건이고, 대기는 기한이 남고 아직 수락 가능한 건입니다. 수락 효과는 수락 주(스케줄이 섞이는 주)를 빼고 직전 주 대비 다음 주의 완료율 차이(pp)로, 직전 주는 루틴 계보 전체 기록, 다음 주는 수락으로 적용된 버전의 기록만 귀속합니다. 측정은 다음 주가 끝나고 day-end 배치 확정 여유를 하루 둔 월요일(KST)부터 시작하며(그전엔 대기), 전후 어느 주에 귀속 기록이 없거나 루틴이 삭제되면 측정 불가로 셉니다. 추천 문구·제안 내용은 노출하지 않고 건수만 집계합니다.
