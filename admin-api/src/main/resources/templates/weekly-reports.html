AI 주간 회고 생성 관측

주(일~토 KST)마다 회고 대상 사용자 대비 생성·FALLBACK·누락 건수를 확인합니다.

최근 주 대상 사용자 — 그 주 루틴 기록이 있는 활성 회원
생성 완료 — LLM 요약·제안 포함
FALLBACK — LLM 실패 후 통계·고정 문구로 저장
커버리지 — 누락 = 대상 − (생성 + FALLBACK)
지표 기준 대상 사용자는 batch 와 같은 조건(그 주 COMPLETED·FAILED 루틴 기록, 탈퇴 회원·삭제 루틴 제외)을 그 주 배치가 끝난 시각 기준으로 되짚은 값입니다. 배치 이후 완료 취소·루틴 삭제로 기록이 사라지면 생성 건수가 대상 수를 넘을 수 있고 이때는 "기준 변동"으로 표시합니다. 회고 본문은 노출하지 않고 건수만 집계하며, FALLBACK 비율은 생성된 회고 중 LLM 응답 없이 저장된 비율입니다. "대기"는 그 주 첫 배치(일요일 00:30 KST) 이전, "미생성"은 배치가 보류·실패해 한 건도 없는 상태입니다.
