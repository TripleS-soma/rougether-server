기록을 읽는 기준

기존 서버 작업 기록을 KST 하루 단위로 조회합니다. 단순 화면 열기·조회·클릭은 포함하지 않으며, 건수는 화면 방문 횟수가 아닙니다. 취소·삭제·덮어쓰기로 보존되지 않은 기록은 누락될 수 있습니다. 봇·AI·탈퇴 계정은 제외합니다.

‘접속 기록만 확인’은 기능을 사용하지 않았다는 뜻이 아닙니다. 인증 기록은 로그인·토큰 갱신과 하루 최초 인증 요청 기준이며 실시간 온라인 상태가 아닙니다. 일별 인증 여부만 남은 경우 시각은 표시하지 않습니다.

기록이 확인된 사용자—조회 조건에 맞는 사용자
행동 기록이 있는 사용자—접속 기록 외 작업이 있는 사용자
확인된 행동 기록—조회된 사용자의 작업 기록 합계
